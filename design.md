# theoo — Design System

Brand: **theoo** (skincare / beauty)
Tagline: **"Effortless, like you!"**

## Typography

| Role            | Font           |
| ---------------- | -------------- |
| Logo / Headings | League Spartan |
| Body text        | Poppins        |

## Color Palette

| Name            | Hex       | Role                          |
| ---------------- | --------- | ------------------------------ |
| Primary          | `#A6A195` | Warm taupe / greige — main brand color |
| Secondary        | `#C7CBC8` | Sage grey — secondary surfaces |
| Background       | `#F6F4F0` | Off-white / cream — page background |
| Muted / Border   | `#E4E4E4` | Light grey — dividers, borders, muted surfaces |
| Dark Accent      | `#5F5143` | Deep brown — text, dark accents, high-contrast elements |

## Visual Tone & Moodboard

- Clean, minimal, warm-neutral aesthetic — understated rather than flashy.
- Soft, glowing skin close-ups; glossy lips; skincare and makeup product photography.
- Warm neutral tones throughout; avoid loud or highly saturated colors — stay within the palette above.
- Textures: marble, soft skin, product swatches.
- Overall feeling: effortless, gentle, confident beauty.

## Imagery

- Product/brand images live in `public/images/`, numbered sequentially (`1.jpg`, `2.png`, …).
- Prefer photography that matches the moodboard tone (soft light, warm neutrals, close-up beauty/skincare shots) over illustration or stock-generic imagery.

## Usage Notes

- Use the palette above as the theme tokens (e.g. shadcn/Tailwind CSS variables) rather than arbitrary colors.
- Headings and the logo wordmark use League Spartan; all other UI text uses Poppins.
- Keep layouts airy and minimal, consistent with the moodboard's clean beauty-editorial feel.
